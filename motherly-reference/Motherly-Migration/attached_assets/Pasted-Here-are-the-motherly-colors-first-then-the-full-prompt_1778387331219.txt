**Supabase database — create these tables:**

users — id (uuid primary key), email (text unique), role (enum: mother, clinic_staff, admin), created_at (timestamptz default now())

clinics — id (uuid primary key), name (text), location (text), contact (text), created_at

mothers — id (uuid primary key), user_id (uuid references users), name (text), age (int), gestational_age (int), clinic_id (uuid references clinics), due_date (date), created_at

staff — id (uuid primary key), user_id (uuid references users), clinic_id (uuid references clinics), name (text), role (text), created_at

checkins — id (uuid primary key), mother_id (uuid references mothers), bp_systolic (int), bp_diastolic (int), blood_sugar (float), body_temp (float), heart_rate (int), symptoms (text array), notes (text), risk_score (float), risk_level (enum: low, mid, high), created_at

epds_responses — id (uuid primary key), mother_id (uuid references mothers), responses (jsonb), total_score (int), ppd_flagged (boolean default false), created_at

alerts — id (uuid primary key), mother_id (uuid references mothers), clinic_id (uuid references clinics), alert_type (text), message (text), is_read (boolean default false), created_at

RLS policies:
- Mothers can only select and insert their own rows in checkins and epds_responses
- Clinic staff can only select mothers, checkins, epds_responses, and alerts where clinic_id matches their assigned clinic
- Alerts visible only to the clinic they belong to

---

**Risk scoring API:**

Next.js API route at /api/risk. Accepts POST with bp_systolic, bp_diastolic, blood_sugar, body_temp, heart_rate, age, mother_id. Returns risk_level and risk_score.

Thresholds:
- High: bp_systolic above 140, or bp_diastolic above 90, or blood_sugar above 11, or body_temp above 38.5
- Mid: bp_systolic above 130, or bp_diastolic above 85, or blood_sugar above 7.8
- Otherwise: Low

After calculating, update the checkin row with risk_level and risk_score. If high risk, insert into alerts with alert_type "high_risk_vitals" and a message specifying which vital triggered it.
